# Legacy compact-humanoid evidence

This directory contains the complete result tree that existed at the validated
baseline commit `f18e45c407ab4f3769c9900f41169025c34d0733` before the G1
migration. The measurements were generated from the self-contained
`mini_humanoid` model and must not be read as Unitree G1 evidence.

The legacy raw-data source checkpoint recorded in the previous project report
was `3be7824`. The primary experiment after the migration is the pinned
Unitree G1 29-DoF no-hands model under `models/unitree_g1/`; its raw data and
figures live in the top-level `results/` tree and carry independent provenance.
