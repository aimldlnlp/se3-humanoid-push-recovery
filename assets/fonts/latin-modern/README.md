# Latin Modern typography

The visualization pipeline uses the Latin Modern Roman family for text and
Computer Modern math for equations, matching the paper-style TikZ architecture
figure. The four OTF faces are copied from the TeX Live installation on the
validated rendering worker and are bundled so local and worker renders do not
depend on a system-wide font installation.

Source family: Latin Modern, `LM Roman 10`, font version `131334`.
